What I Do

Neuromarketing & BCI

Researching consumer behaviour through brain-computer interface systems. My PhD work focuses on understanding how neural signals can predict consumer traits and preferences, bridging neuroscience and marketing to deliver actionable insights for the industry.

Signal Processing & AI

Expertise in digital signal processing for biomedical applications — EEG and ECG signal analysis, feature extraction, deep learning-based classification, and data-driven modelling. Published work on ECG-based sleep apnea classification and EEG-based consumer trait prediction.

Research Engineering

Building end-to-end research tools — web scrapers for stimulus collection, experiment platforms with EEG and eye-tracker hardware integration, automated data pipelines with Google Cloud APIs, and interactive visualization GUIs for data inspection.

My Work

E-commerce Product Scraper

Multi-platform web scraper (Amazon, Lazada, Shopee) built with Playwright stealth mode. Features human-like scrolling, anti-bot evasion, image deduplication, and AI-powered data sanitization using the Anthropic Claude API. Collects product titles, prices, ratings, images, and details at scale.

Neuromarketing Experiment Platform

Flask-based experiment paradigm integrating Emotiv EEG and Gazepoint eye tracker via Lab Streaming Layer (LSL). Features real-time EEG marker synchronization, baseline recording, timed stimulus presentation, multi-question response flow, session resume capability, and clock synchronization between browser and LSL streams.

Product Data Viewer

Local web-based GUI for inspecting and filtering scraped product data. Features category and platform filters, full-text search, image galleries with modal zoom, missing-field warnings, and a jump bar for quick navigation across hundreds of products.

Survey Data Pipeline

Automated Google Forms response extraction using Google Cloud service accounts (Sheets & Drive APIs). Incremental processing with state tracking — only exports new responses on each run. Used for pre-test questionnaire data (demographics, personality, shopping behaviour) in the neuromarketing study.
